# Step

Шаг запуска: золотой номер в круге, заголовок и одна фраза. Передайте `n`, `title` и текст в `children`; кладите шаги в `<ol>` с зазором `space-7`.

Четыре шага — предел; заголовок — существительное («Заявка», «Запуск»), фраза — что вы делаете для партнёра. Линию-рельс между кругами и её заполнение при прокрутке рисует страница.

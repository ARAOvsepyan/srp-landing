# ClubMedal

Круглая «медаль» с логотипом клуба на тёмной подложке и краем `line-strong`. Передайте `src` (файл из группы Clubs), `alt` и `size` (84 по умолчанию, 76 в карточке, 112 в герое каталога).

Логотип вписывается по `contain` в 82% круга и не перекрашивается: у каждого клуба свои цвета. Для декоративной стены (бегущая строка) передайте пустой `alt`, для одиночного клуба — «Логотип клуба <название>, <город>».

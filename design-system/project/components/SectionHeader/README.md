# SectionHeader

Заголовок секции: метка `eyebrow` золотом, заголовок `h2` и необязательная подводка. Передайте `eyebrow`, `title`, `accent` (одна фраза, которая получит золотой градиент `gold-metal`) и `sub`.

Один `accent` на заголовок, не больше 22 символов в строке, без точки в конце. Метка называет раздел («Сеть в цифрах», «Для партнёров»), а не повторяет заголовок. `align="center"` центрирует блок для секций с одной колонкой.

# Field

Поле формы с подписью, подсказкой и ошибкой: обычный `input` или `select`, если передан `options` (`[{value, label}]`). Остальные свойства (`name`, `type`, `placeholder`, `required`, `value`) уходят в сам элемент.

Граница поля — `control-border` (не ниже 4.5:1), при ошибке — `danger` и фраза под полем: цвет всегда сопровождается словами. Подпись над полем, а не placeholder внутри: placeholder только пример. Высота 48px, фокус — кольцо `focus-ring`. Согласие на обработку данных — отдельный чекбокс на странице.

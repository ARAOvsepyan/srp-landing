# NetworkMap

Карта России с пинами клубов и золотыми дугами от хаба (по умолчанию Москва) — главное доказательство масштаба сети. Передайте `mapSrc` (файл `map-russia.svg` из группы Map), `pins` — массив `{lat, lon, label?}`, при желании `ghosts` — города без клуба `{lat, lon}`, `hub` и `lit`.

`lit` — сколько ближайших к хабу пинов уже горит (по умолчанию все): страница увеличивает его при прокрутке, и дуги дорисовываются. Подписывайте `label` не больше семи городов. Призрачные пины — приглашение «здесь может быть ваш город», а не обещание свободной территории. Блок тянется на всю ширину контейнера с пропорцией 1480 × 770.

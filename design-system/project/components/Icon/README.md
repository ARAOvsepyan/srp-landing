# Icon

Линейная иконка 24px со штрихом 1.6 и скруглёнными концами, цвет берёт из `currentColor`. Задайте цвет родителю: золотой (`gold`) для акцентов, `ink` внутри текста.

Имена: `crown`, `shield`, `blocks`, `chart`, `tv`, `cap`, `trophy`, `arrow`, `check`. Размер — `size`, по умолчанию 24; в карточке преимущества — 44. Без подписи иконка скрыта от скринридера; если она несёт смысл сама, передайте `title`.

Не смешивайте с другими наборами и не используйте эмодзи. Для файла-картинки есть группа Icons, но там цвет зашит (`#dcc77f`).

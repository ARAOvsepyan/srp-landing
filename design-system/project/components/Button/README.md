# Button

Кнопка действия: золотая заливка для главного шага, призрачная для второго, бордовая только в шапке. Золотая (`gold`) — не больше одной на экран и всегда с глаголом: «Оставить заявку», «Узнать условия запуска». Призрачная (`ghost`) — парное действие рядом («Смотреть сеть на карте»). Бордовая (`burgundy`) — единственная кнопка шапки.

Передайте `href`, чтобы получить ссылку `<a>`, иначе это `<button type="button">`. `icon="arrow"` добавляет стрелку справа. `size="sm"` для шапки и поисковых полей, `block` растягивает на всю ширину формы.

Не ставьте две золотые рядом и не меняйте цвет подписи: на золоте это `on-gold`, на бордовом `on-burgundy`. Высота от 44px, фокус — кольцо `focus-ring`.

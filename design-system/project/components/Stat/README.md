# Stat

Цифра сети в золотом градиенте с подписью и примечанием. Передайте готовую строку `value` с разделителем разрядов и единицей («30 000+», «69%»), `label` и `note`. `size="sm"` даёт цифру `numeral` (40px) для полосы под героем и для четырёх цифр в ряд: «30 000+» при 62px не помещается в четверть контейнера, поэтому `numeral-xl` ставьте не больше трёх в ряд. Значение не переносится.

Цифра — только подтверждённая; «+» значит «и больше». Четыре цифры в ряд — максимум, и тогда только `size="sm"`. Счётчик, который доезжает до значения за 1.7 с, делает страница: компонент показывает конечное число.

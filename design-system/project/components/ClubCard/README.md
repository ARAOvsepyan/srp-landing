# ClubCard

Карточка клуба в каталоге: медаль, город, название, одна строка о клубе, адрес и телефон. Передайте `logo`, `city`, `name`, `address`, а `phone` и `blurb` — если они подтверждены.

Телефон становится ссылкой `tel:`; номер пишите как «+7 (969) 600-00-16». Нет описания или телефона — строки просто не выводятся, пустых заглушек нет. Город в метке `eyebrow` всегда золотом, название — `h3`. Карточки идут сеткой от 280px, фильтр по городу и поиск — на странице.

# FeatureCard

Карточка преимущества: иконка, заголовок `h3` и две-три строки. Передайте `icon` (имя из `Icon`), `title` и текст в `children`. `featured` подсвечивает одну карточку в ряду краем `line-strong` и заливкой `gold-wash`.

Шесть карточек в сетке 3 × 2 — предел; текст не длиннее трёх строк. Заголовок называет выгоду, текст даёт факт. На наведение край становится `line-strong`; наклон за курсором добавляет страница, не компонент.

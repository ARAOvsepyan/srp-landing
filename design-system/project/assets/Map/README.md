# Map

- `map-russia.svg` — карта России 1480 × 770: все регионы одним контуром, заливка `#231f16`, золотой край с прозрачностью 40%.

Картинка вставляется через `<img>`; пины и дуги кладутся поверх в процентах по формуле equirectangular: `x = (lon − 19) / 161`, `y = (82 − lat) / 41`. Тот же расчёт делает компонент `NetworkMap`. Карту нельзя перекрашивать и обрезать по высоте: проекция растянута, иначе города съедут.

# Logos

- `logo-srp-wordmark.png` — курсивная надпись «СРП» в золотом градиенте на прозрачном фоне, 400 × 80. Растровый файл со своим градиентом; цвет не меняется.

Ставьте только на `surface-0` – `surface-3`. В шапке высота 22px (18px на телефоне), вокруг свободное поле не меньше высоты буквы. Не растягивайте, не добавляйте тень и не помещайте на светлый фон: там золото теряет контраст. Эмблема-маскот со старого сайта в систему не входит.

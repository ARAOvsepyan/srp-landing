# Icons

Девять линейных иконок 24px: `arrow`, `blocks`, `cap`, `chart`, `check`, `crown`, `shield`, `trophy`, `tv`. Штрих 1.6, скруглённые концы. Каждый файл — одноцветный SVG с цветом `#dcc77f` (`gold`), зашитым в штрих: через `<img>` он не наследует `currentColor`. Нужен другой цвет — берите компонент `Icon`.

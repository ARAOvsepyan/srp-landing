# Анализ srppoker.ru (12 октября 2026)

Источники: HTML страницы (642 КБ), просмотр в браузере на десктопной и узкой ширине, сверка с локальными материалами SRP (`club-logos/`, CRM-записи, `Poker Club Manager`).

## 1. Что это

Одностраничник на **Tilda** (Zero Blocks), за DDoS-Guard. Тёмный фон с золотом `#DCC77F`, бордовая кнопка «Оставить заявку». Заголовки — геометрический гротеск, в акцентах курсив. Яндекс.Метрика `110446705`, cookie-баннер.

**Аудитория на деле — партнёры/франшиза** («стань лидером в своём городе»). Игрокам на сайте нечего делать: нет поиска клуба, расписания, ссылки на приложение.

### Структура сверху вниз
1. Шапка: меню (О СРП, Лига городов, Преимущества, IT, Клубы, Отзывы) + «Оставить заявку»
2. Hero: «федеральная сеть спортивно-развлекательного покера в России», 20+ клубов, 30 000+ участников, CTA «Связаться»
3. «СРП — больше, чем клуб» + предупреждение «никаких денег, призовых фондов, рейка»
4. «Почему СРП» — 4 карточки (легально, финансовая стабильность, Лига городов, ТВ)
5. Лига городов + два столбца «Для действующих клубов» / «Для партнёров»
6. IT-инфраструктура (одно предложение + скриншот)
7. «Лучшие клубы России»: 20+ клубов, 52 000+ посетителей в месяц, 30 000+ игроков, 69% удержание
8. Карточки клубов (17 штук)
9. Отзывы партнёров (8, анонимные)
10. FAQ (4 вопроса), финальный CTA, футер с реквизитами ИП

## 2. Что работает
- Чёткое позиционирование и узнаваемая тёмная золотая эстетика.
- Есть количественные доказательства (20+, 30 000+, 52 000+, 69%).
- Два сценария для бизнеса: открыть новый клуб и подключить существующий.
- Честная оговорка «без денег», FAQ про 244-ФЗ и 18+.
- Есть метрика, canonical, viewport, политика ПДн и согласие.

## 3. Проблемы

### 3.1 Продажи и конверсия
| Проблема | Почему важно |
|---|---|
| Единственный CTA — всплывающая форма без объяснений, что дальше | Покупатель франшизы не понимает, чего ждать |
| Нет условий: формат, что входит, этапы запуска, сроки | Главный вопрос франшизы остаётся без ответа до звонка |
| Нет пути для игрока (клуб рядом, приложение, расписание) | 30 000 игроков в комьюнити, а канала для них нет |
| Отзывы без имён, лиц и клубов-логотипов | Анонимный отзыв почти не работает как доказательство |
| Сеть показана текстом, не картой | Масштаб (20+ городов) не считывается за 3 секунды |
| Лига городов описана общими словами, без механики | Сильнейшее отличие сети раскрыто слабее всего |
| IT-платформа — одна фраза и картинка | У СРП есть реальные CRM и приложение, это сильный аргумент |

### 3.2 Неактуальные и противоречивые данные
- **«От Санкт-Петербурга до Сахалина»**: ни в карточках, ни в `club-logos/` нет клуба восточнее Омска.
- **«20+ клубов»** при 17 карточках (16 уникальных клубов; **Омск River Room дублируется**). При этом в `club-logos/` 24 клуба: на сайте нет Альметьевска, Брянска, Йошкар-Олы, Липецка, Обнинска, Оренбурга, Уфы, Чебоксар. Брянск уже стоит в расписании Лиги городов в CRM.
- **Тюмень «скоро, до встречи 5 сентября»**: дата прошла 5 недель назад.
- «30 000+» повторяется как «участников комьюнити» и «игроков в сети».
- Карточки клубов: стена эмоционального текста, телефоны в разных форматах, нет `tel:`-ссылок, нет карты и фильтра по городу.

### 3.3 Тексты
- «Срп — это…», «любые форма азартных игр», «ПАРТНЕРОВ» без «ё» рядом с «ПАРТНЁРОВ», «лучшие клубы россии» с маленькой буквы.
- Отзыв Омска: «ту мечту, который был наш покерный клуб».
- Колонки «Для действующих клубов» и «Для партнёров» почти дублируют друг друга (CRM, Лига городов).
- Ответ на «Что нужно, чтобы открыть клуб?» — «Любовь к покеру и связаться с нами». Шутка вместо ответа.

### 3.4 Юридические формулировки (нужна проверка юристом)
- «Абсолютно легально» и «соответствует 244-ФЗ» заявлены как безусловный факт.
- **«Окупаемость в течение первого года»**: гарантия финансового результата без обоснования. Для рекламы франшизы это зона риска.
- Видимой маркировки 18+ на первом экране нет (возраст упомянут только в FAQ).

### 3.5 Техника
- Tilda Zero Blocks: фиксированные позиции в пикселях. На ширине окна ~800 px текст hero обрезался («РАЛЬНАЯ СЕТЬ»).
- 46 `<script>`, около 26 JS-библиотек Tilda; HTML 642 КБ.
- 17 `<img>`, **ни одного `alt`**; в моём прогоне часть фото (блок отзывов) оставалась чёрными плашками (lazy-load).
- `<html>` без `lang`; 1 `h1`, 9 `h2` (структура есть, но блоки собраны из div-ов).
- Нет JSON-LD, нет `tel:`-ссылок.
- `og:image` — скриншот с именем `2026-07-06_08-42-43.png`.
- `meta keywords` набит фразами (поисковики его не используют).
- Якоря вида `#rec2401496441`, нестабильные при правках в Tilda.
- Одна страница на всё: нет страниц городов, значит нет шансов на запросы «покерный клуб Казань».

### 3.6 Бренд
- В шапке сайта эмблема-маскот, в CRM и приложении курсивный золотой вордмарк «СРП». Два логотипа.
- Сайт тёмный с золотом и бордовой кнопкой; приложение — другой язык (слоновая кость, сукно). Для лендинга для покупателей сохранён тёмный золотой образ сайта.

## 4. Что сделано в новом лендинге

| Находка | Решение |
|---|---|
| Масштаб не считывается | Hero с картой России и дугами от Москвы; sticky-сцена: города загораются по мере прокрутки, счётчик «N из 24», затем карта уезжает к «новым городам» |
| Нет проверки города | Поле «Проверьте свой город»: есть клуб — показывает, нет — переносит город в форму заявки |
| Анонимность, сухость | Параллакс-слои (фишки, карты, ghost-слова), счётчики, 3D-наклон карточек, бегущая стена логотипов 24 клубов |
| Нет пути для игрока | Каталог клубов: поиск, фильтр по городу, `tel:`, Telegram |
| Лига городов расплывчата | Три лиги из CRM: Рейтинга, Чемпионов, Городов |
| IT = одна фраза | Секция платформы с реальными записями CRM (3 вкладки) |
| Нет процесса запуска | Таймлайн из 4 шагов, линия рисуется при прокрутке |
| Нет SEO-основы | `lang`, JSON-LD (организация + клубы), alt у картинок, sitemap/robots, нормальный OG |
| Юридический риск | Без гарантий окупаемости; видимый 18+; текст про 244-ФЗ перенесён как есть, **ждёт проверки** |
| Тяжесть | Весь сайт около 1.6 МБ вместе с видео и картинками; нет сторонних скриптов до согласия на cookie |

6. Куда присылать заявки (endpoint, Telegram, CRM).
7. Реальные фото и видео клубов, имена и фото партнёров для отзывов.
8. Условия партнёрства для страницы (вложения, роялти, сроки) или решение их не публиковать.
